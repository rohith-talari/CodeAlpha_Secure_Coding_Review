# Secure Coding Review

This project was developed as part of the CodeAlpha Cyber Security Internship.

The project demonstrates both vulnerable and secure authentication systems using Python and SQLite. It explains common security issues like SQL Injection and weak password hashing.

## Features
- Vulnerable login system
- Secure login system
- SQL Injection demonstration
- Password hashing using bcrypt
- SQLite database integration

## Technologies Used
- Python
- SQLite
- bcrypt

## How to Run

Install bcrypt:

pip install bcrypt

Run secure version:

python auth_system_secure.py

Run vulnerable version:

python auth_system_vulnerable.py

## Security Concepts Covered
- SQL Injection
- Weak password hashing
- Secure password storage
- Parameterized queries

## What I Learned
- Common authentication vulnerabilities
- Secure coding practices
- Importance of password hashing
